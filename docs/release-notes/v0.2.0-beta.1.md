## 🌟 Overview & Highlights

**LearnUp Desktop v0.2.0-beta.1** is the first official pre-release distribution of LearnUp Desktop tailored specifically for Windows users. It packages the complete LearnUp learning platform into a clean, lightweight (~15MB installed, 2.52MB installer) native Windows application built on Tauri 2, React 18, and Rust.

This release achieves **100% design and feature parity with LearnUp-Web**, while offering true offline-first SQLite persistence, YouTube lecture timestamping, Pomodoro focus sanctuary, markdown note-taking, and multi-profile isolation.

## 🚀 What's Included in This Release

### 1. 📴 Offline-First Local Persistence
- High-performance SQLite engine with Write-Ahead Logging (WAL) and multi-process safety.
- Complete data isolation across Guest profiles and personalized user workspaces.
- Seamless upgrade path: Upgrading the application replaces binary files while strictly preserving your local `learnup.db` SQLite database located at `%APPDATA%\com.learnup.desktop\`.

### 2. 🎨 Full UI & Settings Parity with LearnUp-Web
- Cohesive dark mode design language aligned with the web platform.
- Comprehensive 14-section Settings interface covering Account & Profiles, Cloud Sync, Security & MFA, Appearance, Focus Timer, Learning Preferences, AI Providers, Connectors, Plugins, and Data Privacy.
- Responsive layout adapting to various Windows window dimensions (minimum 960x600, default 1280x800).

### 3. 🎥 YouTube Learning & Active Bookmarks
- Native YouTube iframe embedding with keyboard shortcuts (Space to toggle play/pause, Left/Right for scrubbing).
- Instant timestamped bookmarks and notes linked directly to lecture playback markers.

### 4. ⏱️ Focus Sanctuary
- Integrated Pomodoro timer supporting work intervals, short breaks, and long breaks.
- Visual study progress tracking and historical streak analytics.

### 5. 🔄 Cloud Sync & Community Marketplace Foundation
- Idempotent local mutation journal designed for safe, zero-loss cloud replication with Supabase (SF-122 / SF-130).
- Cloud synchronization remains strictly **opt-in**; guest learning data is never uploaded without explicit user authorization.

## 📥 Installation Instructions for Windows Users

1. **Download Setup**:  
   Download `LearnUp Desktop_0.2.0-beta.1_x64-setup.exe` from the Assets table below.

2. **Launch Setup**:  
   Double-click the installer executable.

3. **Bypass Windows SmartScreen**:  
   Because this is an open-source community release that has not yet acquired an enterprise code signing certificate, Windows Defender SmartScreen may display:  
   > *"Windows protected your PC"*  
   - Click **More info**  
   - Click **Run anyway**  
   *(The full source code and build recipes are completely open and auditable on GitHub).*

4. **Complete Setup Wizard**:  
   Follow the NSIS installation wizard. The app will install into `%LOCALAPPDATA%\Programs\LearnUp Desktop` without requiring administrator privileges.

5. **Launch Application**:  
   Launch LearnUp Desktop via your desktop shortcut or Start Menu.

## 🔍 Known Limitations & Beta Disclaimers

- **Public Beta Status**: This is a beta preview release intended for user testing and community feedback.
- **Code Signing**: The installer is currently unsigned. SmartScreen will show a warning on first launch.
- **Cloud Sync Default**: Cloud sync transport is inactive by default in this build to safeguard user privacy until server endpoints are finalized.
- **Reporting Issues**: Please submit any issues or feature feedback at <https://github.com/Kadhiravan-K/LearnUp--Desktop/issues>.
