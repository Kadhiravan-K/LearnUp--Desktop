## 🌟 Overview & Highlights

**LearnUp Desktop v0.2.0-beta.2** stabilizes the Windows desktop application with release-critical fixes, enhanced player controls, full settings parity, and verified real-world curriculum integration:

1. **Course Ingestion & Playback Hardening**: Fixed Rust Serde deserialization for course tags, added YouTube Data API v3 pagination with transparent RSS truncation warnings, and resolved iframe origin blocking (YouTube Error 150) with sequential lesson navigation controls.
2. **LearnUp Custom Player Engine**: Integrated the dedicated player engine with interactive Keyboard HUD shortcuts overlay, 2x speed boost on hold, gesture badges, and instant bookmark timestamp seeking.
3. **Accent Spectrum & Dynamic Themes**: Unified `<ThemeProvider>` context across Settings and Header; clicking color pills dynamically applies custom primary and accent variables (`--sf-color-primary`, `--sf-accent-primary`, etc.) across all buttons, borders, and active states.
4. **Production-Ready Multi-Provider AI Studio**: Configured live endpoints for Google Gemini, Anthropic Claude, OpenAI, Groq LPU, OpenRouter, and local Ollama (`localhost:11434`) with real network ping latency measurements.
5. **Real-World Curated Blueprint Catalog**: Replaced static mock items with verified university courses and playlists (Harvard CS50, Andrej Karpathy Deep Learning, 3Blue1Brown Linear Algebra, MIT 6.006 Algorithms, Stanford CS229 ML, NeetCode DSA, Gaurav Sen System Design, freeCodeCamp Full-Stack) that import directly into local SQLite.
6. **Authentication & Profile Security**: Added multi-profile chooser, guest profiles, secure PIN/password lock, and clean session termination on sign-out.
